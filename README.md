# Synapse Control

**Synapse Control** is a universal assistive hub explicitly designed for differently-abled individuals. It acts as a cohesive operating system bridging multiple assistive technologies into a single, seamless, and stunning interface.

## Features

- **AAC Communication Pad:** Text-to-speech functionality with quick speech commands for everyday conversational phrases.
- **Voice Assistant:** Native speech recognition integration allowing hands-free voice commands.
- **Switch Scanning (Simulated):** A robust scanning engine designed to support one-switch or two-switch users.
- **Smart Home Integrations:** Voice and click-based integrations for controlling connected lights, temperature, and doors.
- **Accessibility Layers:** Dynamic visual settings including high-contrast mode, dyslexic typography profiles, colorblind corrections, and large cursor capabilities.
- **Visual Feedback:** WebAudio HIFI sound cues and live visualizer wave mechanics to provide sensory affirmation.

## Technologies Used
- HTML5 / CSS3 / JavaScript (Vanilla JS Core)
- WebAudio API
- Web Speech API (SpeechSynthesis & SpeechRecognition)
- Vite (Build Tool)

## Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) installed on your machine.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Charan31106/synapse-control.git
   cd synapse-control
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```

## Deployment

This application is ready to be deployed to Vercel. Connect this GitHub repository directly to Vercel for zero-config deployments.
